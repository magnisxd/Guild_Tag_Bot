# Guild_Tag_Bot
# 🏷️ Discord Guild Tag Bot  Sunucunuzdaki üyelerin kullanıcı adlarında veya durumlarında yer alan sunucu taglarını/etiketlerini otomatik olarak tespit eden, tag alan kullanıcılara özel roller tanımlayan ve tag çıkaranlardan rolü geri alan gelişmiş yönetim botu.  ### 🚀 Öne Çıkan Özellikler * **Otomatik Tag Tespiti:** Kullanıcı adına eklenen tagı anında algılar ve belirlenen rolü verir. * **Tag Çıkarma Takibi:** Tagı silen kullanıcıdan ilgili rolleri çeker ve yetkilileri bilgilendirir. * **Detaylı Loglama:** Tag alan/bırakan kullanıcıları log kanalında anlık olarak raporlar. * **İstatistik ve Sayım:** Sunucuda kaç kişinin tag taşıdığını anlık olarak listeler.
